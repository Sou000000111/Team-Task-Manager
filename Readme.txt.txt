# Team Task Manager 🚀

A full-stack Team Task Manager web application where users can create projects, assign tasks, manage team workflow, and track progress with role-based authentication.

## Live Demo

Frontend + Backend Live URL:

https://selfless-blessing-production-38d1.up.railway.app

---

## 📌 Features

### Authentication
- User Signup
- User Login
- JWT Authentication
- Protected Routes

### Role-Based Access
- Admin Role
- Member Role
- Secure API authorization

### Project Management
- Create Projects
- View Projects
- Project Status Tracking

### Task Management
- Create Tasks
- Assign Tasks
- Due Dates
- Task Status Tracking

###  Dashboard
- Overview of projects
- Task statistics
- Status management
- Overdue task tracking
